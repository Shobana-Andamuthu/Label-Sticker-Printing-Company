Prepress Standards

File Preparation & Setup Guidelines

Follow these essential prepress standards to ensure razor-sharp text, rich color gamut fidelity, and microscopic laser cutline accuracy.

Step 01

1. Resolution (300+ DPI)

All raster image artwork (photos, gradients, bitmaps) must be created at a minimum of 300 DPI at 100% final print scale to eliminate pixelation and edge blur.

Step 02

2. Color Mode (CMYK / PMS)

Design in CMYK color space (GRACoL 2013 coated). RGB files will be automatically converted, which can cause shifts in bright saturated screen tones.

Step 03

3. Bleed & Safe Zone

Add 1/16" (0.0625" / 1.5mm) full bleed extending beyond the cutline. Keep all vital typography and logos 1/16" inside the safe margin boundary.

Step 04

4. Convert Text to Outlines

Convert all live typography to vector paths/curves (Type > Create Outlines or Ctrl+Shift+O) to ensure no missing font substitutions occur on press.

Step 05

5. Vector Cutline Layer

Define custom cutlines on a separate top layer as a 0.5pt stroke using a 100% Magenta spot color named DieCut or CutLine.

Step 06

6. Accepted File Types

We accept vector PDF (preferred), AI, EPS, SVG, or high-res PSD, PNG, and TIFF up to 50MB per upload.
